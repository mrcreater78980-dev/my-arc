# MY ARC

Өдөр бүрийн ажил, дадал, суралцах ахицаа нэг дор хөтлөх Flutter апп.

## Эхлүүлэх

Flutter SDK 3.27 буюу түүнээс хойших хувилбар болон Dart SDK 3.6+ шаардлагатай.

```bash
flutter pub get
flutter run
```

Chrome дээр ажиллуулах бол:

```bash
flutter run -d chrome
```

## Ашиглах

- Нүүр хэсгээс өнөөдрийн ажлууд, дадал, суралцах чиглэлээ харна.
- Доод цэсээр ажил, дадал, ур чадвар, ахицын хэсгүүд рүү шилжинэ.
- Ажил болон дадал нэмэх, биелэлтийг тэмдэглэх, суралцах сессээ бүртгэх боломжтой.
- Аппын төлөв төхөөрөмж дээр хадгалагдаж, дахин нээхэд сэргээнэ.

## Хөгжүүлэлт

```bash
flutter analyze
flutter test
```

Дэлгэцүүд `lib/screens/` хавтсанд, загвар ба өгөгдлийн бүтэц `lib/models/` хавтсанд, төлөвийн удирдлага `lib/state/` хавтсанд байрлана.
